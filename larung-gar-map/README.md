# 喇荣五明佛学院 · 活点地图 (Larung Gar — Marauder's Map)

一张以《哈利·波特》活点地图（Marauder's Map）为灵感的**喇荣五明佛学院**互动地图。
羊皮卷风格、纯手绘 SVG，山谷里布满标志性的绛红色小木屋，可点击各处圣地查看简介。

## 打开方式

直接用浏览器打开 `index.html` 即可 —— **零依赖、零网络**，离线可用。

```bash
# 任选其一
open larung-gar-map/index.html          # macOS
xdg-open larung-gar-map/index.html      # Linux
# 或在仓库根目录起个本地服务器
python -m http.server 8000              # 然后访问 http://localhost:8000/larung-gar-map/
```

## 玩法

1. 念出咒语 **“I solemnly swear I am up to no good”** 按钮展开地图。
2. 轻点金色标记，右侧浮现该圣地的介绍（坛城、大经堂、觉姆/扎巴红房子区、法王灵塔、观景台等）。
3. **拖拽**平移、**滚轮**缩放、`复位` 回到初始视角。
4. 坛城周围有沿转经道行走的脚印动画 —— 活点地图“活”的部分；`恶作剧完成` 可隐藏脚印。

## 地理锚点

喇荣五明佛学院位于四川省甘孜州色达县，海拔约 3700m，
约 31.999°N, 100.345°E。地图为**写意示意**，非精确测绘 —— 各标记坐标为近似值，仅供示意。
